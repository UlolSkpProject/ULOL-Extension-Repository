# 프로젝트 지침: 치수 기반 Texture 제작

최종 Texture는 이미지 생성 모델이 만든 결과를 그대로 사용하지 않는다.
이미지 생성 모델은 재질의 색상, 표면 질감, 오염 정도, 반사 제거 등 **시각적 재질 표현을 만드는 용도**로만 사용한다.
최종 이미지의 크기와 모든 내부 구간(타일·패널·줄눈·문·창 등)의 경계는 반드시 픽셀 좌표를 기준으로 후처리하여 강제로 맞춘다.

## 0. 핵심 원칙 (전역 리사이즈 금지)

전체 이미지에 대한 단일 리사이즈 또는 단일 원근 보정만으로는 여러 개의 독립적인 목표 치수를 동시에 만족시킬 수 없다. 원본 사진/생성 이미지의 내부 비율은 사용자가 지정한 목표 비율과 다르기 때문이다.

- 사용자가 지정한 모든 구성요소(문, 창, 패널, 줄눈, 베이스 등)를 **독립된 사각형 영역(bounding box)**으로 먼저 목록화한다.
- 각 구성요소는 원본에서 **개별적으로 크롭**한 뒤, **x축·y축 스케일 팩터를 각각 별도로 계산**하여 리사이즈한다. (원본 가로세로 비율 유지 가정을 버릴 것. 목표 mm 규격이 우선이며, 필요하면 비균등 스케일을 적용한다.)
- 리사이즈된 각 구성요소를 목표 픽셀 좌표에 맞춰 캔버스에 합성한다.
- 전체 이미지를 한 번에 리사이즈/워핑하는 방식은 금지한다. (이는 참조 사진이 1장뿐인 경우에도 동일하게 적용된다 — 0-4항 참조)

## 0-1. 다중 참조 이미지 처리 원칙

사용자가 동일 대상을 여러 각도/거리에서 찍은 사진을 다수 제공하는 경우, 이를 캔버스에 물리적으로 이어붙이거나 그리드로 배치하는 것은 절대 금지한다. 여러 장의 사진은 각각 다음 두 가지 용도로만 사용한다.

1. **각 구성요소(문, 패널, 측면 프레임 등)마다 가장 정면에 가깝고 왜곡이 적은 사진 1장을 대표 소스로 선정**한다. (여러 각도의 사진을 짜깁기해서 하나의 구성요소를 만들지 않는다.)
2. 선정된 대표 소스에서 필요한 구성요소만 크롭 → 원근 보정 → 재질/색상 추출 후, 캔버스의 지정 좌표에 배치한다.

최종 결과물에는 다음이 있어서는 안 된다.
- 서로 다른 사진 조각이 이어붙여진 격자선(seam line)
- 인접 영역 간 노출·반사·색온도 불일치로 인한 경계선
- 원본 사진의 프레이밍(촬영 위치, 촬영 거리)이 그대로 드러나는 흔적

부득이 여러 소스를 한 구성요소에 블렌딩해야 한다면(예: 그림자 제거를 위해 2장 합성), 히스토그램 매칭 또는 노출 정규화를 거쳐 이음선이 육안으로 보이지 않게 하고, 검증 단계에서 **이음선 존재 여부**를 별도 항목으로 확인한다.

## 0-2. 제거 대상 요소 검증 강화

사용자가 "무시" 또는 "제거"를 지정한 요소(안내판, 표지판, 사람, 케이블 등)는 다음과 같이 처리한다.

1. 마스킹 및 인페인팅으로 제거한다.
2. 최종 이미지 저장 후, 해당 요소가 남아있는지 **재확인**한다. (해당 좌표 영역 크롭 후 육안/OCR 확인 등)
3. 잔존이 확인되면 결과를 전달하지 않고 재처리한다.
4. 최종 보고 시 "제거 대상 요소별 제거 확인 결과"를 표로 명시한다.
5. 사용자가 유지/제거 여부를 명시하지 않은 요소(표시등, 버튼 패널 등)가 있으면, 임의로 판단하지 말고 0-3 절차에 따라 먼저 확인받는다.

## 0-3. 치수 모호성 사전 확인 원칙

사용자가 제공한 치수/도면에 다음 중 하나라도 해당하면 이미지 생성 전에 반드시 해석안을 표로 제시하고 사용자 확인을 받은 뒤 진행한다. 확인 없이 임의로 추정해서 생성하지 않는다.

- 값이 명시되지 않은 변수(예: x, y, "알 수 없음")가 있는 경우
- 같은 축(가로 또는 세로)에 대해 서로 다른 치수 그룹의 합이 일치하지 않는 경우 (예: 상단 구간 합 680mm ≠ 하단 구간 합 3400mm)
- 여러 장의 참조 사진이 있고 어떤 사진 요소를 유지/제거할지 명시되지 않은 경우 (예: 표시등, 버튼 패널, 안내문, 스티커 등)

해석안 제시 시 반드시 포함할 내용:
- 각 모호한 항목에 대한 해석(가정)과 그 근거 (원본 사진 실측값, 인접 치수와의 정합성 등 구체적 근거 필수 — "적당히", "일반적으로" 같은 근거 없는 추정 금지)
- 미지수는 원본 참조 이미지에서 실측한 픽셀/비율 근거를 제시
- 사용자 확인 후에만 실제 이미지 생성 단계로 진행

## 0-4. 단일 소스 이미지에서도 전체 리사이즈 금지

참조 사진이 1장뿐인 경우에도 0번 항목(전체 리사이즈 금지)은 동일하게 적용된다. 결과물 제출 전 다음을 자체 점검한다.

- 결과 이미지 내 각 구성요소의 상대적 배치·비율이 원본 사진과 거의 동일하다면 (즉 원본을 그대로 리사이즈한 것과 구분이 안 된다면), 이는 실패로 간주하고 좌표 기반 재조립을 다시 수행한다.
- 이 점검 결과("원본과의 배치 유사도 확인 결과")를 최종 보고 표에 포함한다.

## 1. 기본 원칙

1. 사용자가 mm 단위로 규격을 제공한 경우, 최종 이미지에서는 1px = 1mm로 대응한다.
2. 최종 PNG의 가로·세로 픽셀 크기는 사용자가 지정한 실제 mm 크기와 정확히 동일해야 한다.
3. 이미지 생성 모델이 만든 타일 크기, 패널 높이, 문/창 비율, 줄눈 위치는 신뢰하지 않는다.
4. 이미지 생성 결과는 표면 질감 소스로만 사용하고, 최종 배치는 Python, Pillow, OpenCV 등의 이미지 처리 도구를 이용해 정확한 픽셀 좌표로 조립한다.
5. 원본 사진에 원근 왜곡이나 기울어짐이 있으면, **구성요소 분해 이전에** 수직·수평 및 투시 보정을 먼저 수행한다.
6. 사용자가 "무시하라"고 지정한 요소는 0-2 절차에 따라 처리한다.
7. 치수/도면에 모호한 부분이 있으면 0-3 절차에 따라 먼저 확인받는다.
8. 최종 출력 전 반드시 실제 픽셀 크기와 각 구간의 경계 좌표를 프로그램으로 검증한다.

## 2. 제작 절차

1. 사용자가 제공한 치수/도면을 검토하여 0-3에 해당하는 모호성이 있는지 먼저 점검한다. 있다면 해석안을 표로 제시하고 사용자 확인을 받는다.
2. 확정된 목표 bounding box 좌표 표를 작성한다.
3. 참조 사진이 여러 장이면 0-1 절차에 따라 구성요소별 대표 소스를 선정한다. 1장뿐이어도 0-4 원칙이 적용됨을 인지한다.
4. 반사, 그림자, 조명 편차, 원근 왜곡을 제거한다.
5. 대표 소스에서 각 구성요소의 **실제 픽셀 경계를 측정**한다. (수동 좌표 확인 또는 edge/contour detection 코드 사용)
6. 사용자가 지정한 크기의 빈 캔버스를 정확한 픽셀 크기로 생성한다.
7. 구성요소별로 원본 경계 → 목표 경계에 맞춘 **개별 크롭 + 비균등 리사이즈**를 수행한다.
8. 리사이즈된 각 구성요소를 지정 좌표에 합성한다.
9. Seamless texture가 필요한 구간은 이미지 경계가 줄눈 중심 또는 재질 반복 경계를 정확히 통과하도록 만든다.
10. 최종 PNG를 저장한 뒤 프로그램으로 검증 항목을 측정한다.

## 3. 필수 검증 항목

- 최종 이미지의 정확한 가로·세로 픽셀 크기
- 각 구성요소의 실측 폭과 높이 (좌/우/상/하 경계 좌표 포함)
- 줄눈 중심 좌표와 줄눈 폭
- 반복 시 경계가 자연스럽게 연결되는지 여부
- 무시 지정 요소의 완전 제거 여부 (0-2 절차 결과)
- 서로 다른 소스 간 이음선(seam) 존재 여부
- 원본과의 배치 유사도 확인 결과 (0-4 절차 결과 — 리사이즈 여부 판별)
- 모호 치수 해석안에 대한 사용자 확인 여부 (0-3 절차 결과)

## 4. 검증 실패 시 처리

허용 오차는 기본적으로 **±3px**로 한다.

- 실측값이 목표값과 허용 오차를 초과하여 어긋나면, 결과를 그대로 전달하지 않는다.
- 어긋난 구성요소에 대해 크롭/스케일 파라미터를 재계산하여 **재처리**한다.
- 최대 3회까지 자동 재보정을 반복하며, 매 회차 실측값을 기록한다.
- 3회 반복 후에도 오차를 해소하지 못하면, 원본 소재의 한계를 사용자에게 명시적으로 보고한다.

## 5. 최종 출력 원칙

최종 파일을 전달할 때는 다음을 표 형태로 함께 제시한다.

- 파일 크기 (목표 vs 실측)
- 구성요소별 픽셀 크기 (목표 vs 실측)
- 각 구성요소의 경계 좌표 (좌/우/상/하)
- 줄눈 위치 및 Seamless 처리 여부
- 재보정 반복 횟수 및 회차별 실측값 변화
- "무시" 지정 요소 제거 확인 결과
- 이음선(seam) 검사 결과
- 원본 대비 배치 유사도 확인 결과 (전체 리사이즈 여부 판별 근거)
- 모호 치수 항목의 확정 근거 (0-3 확인 이력)

최종 PNG 결과 파일은 항상 다운로드 가능한 링크 형식으로 제공하며, 파일명·픽셀 크기·적용 실측(mm)을 함께 명시한다.
